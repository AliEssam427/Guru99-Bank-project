# Guru99 Bank - Manual Testing Project

## Project Overview

This project demonstrates a complete Manual Software Testing workflow performed on the Guru99 Banking demo application.

Guru99 Bank is a demo banking application used for software testing and QA practice.

The project covers multiple testing activities across different versions of the application, from requirements analysis and test case design to test execution, defect reporting, and requirements traceability.

## Project Objectives

- Analyze software requirements and specifications.
- Design comprehensive test cases.
- Execute functional and integration testing.
- Perform system-level testing.
- Identify and document software defects.
- Maintain traceability between requirements and test cases.
- Provide test evidence for identified defects.
- Validate different application workflows across multiple versions.

## Version 1

Version 1 focuses on the initial requirements and functional testing activities.

### Deliverables

- Software Requirements Specification (SRS)
- Functional Test Cases
- Integration Test Cases
- Bug Reports
- UI Mockups
- Test Execution Evidence

The Screencast folder contains recorded evidence for several identified defects.

## Version 2

Version 2 contains updated requirements and additional testing activities.

### Deliverables

- Updated SRS
- Functional Test Cases
- Integration Test Cases
- Bug Reports

## Version 3

Version 3 expands the testing scope and separates test coverage according to different user roles and system-level behavior.

### Deliverables

- Customer Test Cases
- Manager Test Cases
- System Test Cases
- Updated SRS
- UI Form Mockups
- API Testing Materials

## Version 4

Version 4 includes the Requirements Traceability Matrix (RTM).

The RTM is used to establish traceability between requirements and corresponding test cases, helping ensure adequate test coverage.
